# illustrations

generated with `gpt-image-2.5-sunburst` on a transparent background, then shrunk to 768px and saved as webp in `drawable-nodpi`. the style line in `tools/illustrate.mjs` keeps them in the same family as the nucleo glass icons.

```
node tools/illustrate.mjs chair "A single modern lounge chair made of frosted translucent glass, floating slightly tilted in mid air"
```

| name | where | subject |
|---|---|---|
| chair | hero, floats in the sky between the question and the timer | a glass lounge chair, the hotseat |

each high quality 1024 image takes about 40s.
